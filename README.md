# ABCLog 프론트엔드

아르바이트 경험을 기록하고, 입력한 역량을 모아 관련 직무를 탐색하는 정적 웹사이트입니다. 노동권 점검과 기본급 단순 계산도 제공합니다.

## 실행 방법

프로젝트 폴더에서 `python -m http.server 8000`을 실행한 뒤 브라우저에서 `http://localhost:8000/html/index.html`을 여세요. `html/index.html` 파일을 직접 열어도 대부분의 기능을 사용할 수 있습니다.

## 파일 구성

- `html/`: 각 화면
- `css/index.css`: 공통 디자인, 나머지 CSS: 화면별 디자인
- `js/common.js`: 메뉴와 브라우저 저장소 공통 기능
- `js/experience.js`: 경험 저장·수정·삭제
- `js/competency.js`: 입력한 역량 집계
- `js/job.js`: 직무 검색 및 역량 연결
- `js/labor.js`: 근로조건 점검과 기본급 단순 계산
- `js/auth.js`: 로그인·회원가입 폼의 기본 검증과 연동 준비
- `API/`: 백엔드 연동용 빈 파일. 현재 프론트엔드에는 연결하지 않았습니다.

경험은 현재 브라우저의 `localStorage`에 저장됩니다. 로그인·회원가입 화면은 준비되어 있지만 인증 API와 서버 저장은 아직 연결되지 않았습니다. 비밀번호는 브라우저에 저장하지 않습니다.
